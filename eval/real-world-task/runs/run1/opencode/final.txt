**Artifacts**

**Friction**
- `bash -lc` in the Go image resets PATH and hides `/usr/local/go/bin`; used `bash -c` instead.
- The spec has no tags, so the command is grouped under `api`; `operationId: getEcho` becomes `get-echo`.
- Generated CLI defaulted to bearer auth (auto-detected) but the mock server needs no token, so it worked unauthenticated.
